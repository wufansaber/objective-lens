# UV355 5 mm 最终 F 版

推荐的 UV355 物镜 Zemax 光学处方，物方全视场 5 mm、NA 0.60、13 片、总长 849.99 mm。文件 SHA-256：`049e5b39a476154eafe5b75a28b519f2ae7f863195c3af1ecc463c954ed5a055`。

Zemax 全场最坏 RMS 波前约 0.048038λ；物方场曲约 0.269903 µm，像散约 0.272529 µm。该版本完成名义光学、显式镜片实体及隔圈方案复核；供应商工艺确认、完整公差良率及装配/热验证仍待完成。

ZMX 用于光学追迹，非工作区过渡、支承和隔圈的完整实体定义不由 ZMX 单独表达。公开图表与验证范围见 [UV355 5 mm 案例](https://github.com/wufansaber/standalone-optics/tree/main/examples/uv355-5mm)。
