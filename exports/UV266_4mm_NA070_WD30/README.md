# 266 nm 晶圆检测三物镜

物方线视野 4 mm，切边前物方 NA 0.700，倍率约 10×，沿各路光轴的首面顶点工作距离为 30 mm。三路光轴为 −45°、0°、+45°。CH0 通过 266 nm 单色名义像质验收，CH0、CH1、CH2 均已复核通光和装配干涉。
